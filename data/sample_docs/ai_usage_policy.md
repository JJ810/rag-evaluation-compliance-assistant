# Approved AI Usage Policy

## Purpose

This synthetic policy describes safe use of generative AI tools in a controlled enterprise environment.

## Requirements

Employees may use approved internal AI tools for summarization, drafting, classification, and knowledge retrieval when the source data is authorized for that tool.

Employees must not paste confidential customer data, regulated personal data, secrets, API keys, passwords, unreleased financial results, or proprietary source code into unapproved public AI tools.

External or customer-facing AI-assisted content requires human review before publication. The reviewer must verify factual claims, citations, tone, and policy alignment.

Teams using retrieval augmented generation must track source documents, citations, evaluation results, known limitations, and prompt injection risks.

## Evidence

Acceptable evidence includes AI tool approval records, review checklists, model evaluation reports, and incident records for misuse.
